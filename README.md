
# Saaremaa valla 2025. aasta valimistulemused

## Projekti kirjeldus

Veebileht annab ülevaate Saaremaa valla 2025. aasta kohalike omavalitsuste valimistulemustest, sealhulgas häälte jaotusest, mandaatidest ja valituks osutunud kandidaatidest.

**Eesmärk:** omandada esmased teadmised koodi kirjutamisest ning tutvuda HTML-i, CSS-i ja JavaScripti kasutamisega veebilehe loomisel.

## Kasutatud tehnoloogiad

- HTML
- CSS
- JavaScript

## Õppetöö
